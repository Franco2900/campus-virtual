# Documento de prueba CU-12

Este archivo valida la ingesta de fuentes de conocimiento del chatbot.

## Contenido

El chatbot debe poder recuperar información de este documento cuando un usuario
pregunte sobre la Politica academica de la institution.

## Reglas

- Las consultas se responden con informacion de las fuentes administradas.
- Cada fuente declara los roles a los que aplica.
