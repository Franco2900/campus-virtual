# 4. PREGUNTAS ANTES DE ASUMIR

Después de inspeccionar el proyecto, detecta únicamente las dudas que realmente bloqueen decisiones importantes.

Antes de generar código:

1. Identifica las decisiones que faltan.
2. Separa las dudas críticas de las dudas menores.
3. Pregunta primero las dudas críticas.
4. No preguntes cosas que puedan descubrirse inspeccionando el proyecto.
5. No preguntes por detalles que puedan quedar definidos mediante las convenciones ya existentes.
6. Si varias preguntas están relacionadas, agrúpalas.

Nunca inventes una respuesta para evitar una pregunta necesaria.

Cuando exista información suficiente para continuar, no hagas preguntas innecesarias.
